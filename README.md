# 2048 Game

A clean, self-contained 2048-style sliding number puzzle you can play in the browser.

## Play it

Once GitHub Pages is enabled, the game will be live at:

**https://abhinavraj111.github.io/2048-game/**

### Enable GitHub Pages (one-time setup)

1. Go to the repository: https://github.com/abhinavraj111/2048-game
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Choose branch **main** and folder **/ (root)**
5. Click **Save**

After a minute or two the game will be available at the link above.

## How to play

- Use **arrow keys** or **swipe** on mobile to move the tiles
- When two tiles with the same number touch, they merge into one
- Goal: create the **2048** tile

Enjoy!
